# docs/wiki

These files **are** the [GitHub wiki](https://github.com/rios-kitchen/PokePetExplorer/wiki) – the player guide (中文 / English), the FAQ and the developer notes.
Edit them here: every push to `main` that changes this folder publishes them to the wiki
(`.github/workflows/wiki.yml`). Don't edit the wiki on GitHub directly – the next sync would overwrite it.

Page names are the file names (`05-Outings.md` → `wiki/05-Outings`); link between pages with `[text](05-Outings)`.
`_Sidebar.md` and `_Footer.md` are shown on every page.
