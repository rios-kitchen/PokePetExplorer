# 日记、表情和其他 · Diary, emotions and more

## 中文

- **日记**：宝可梦每天用自己的话写日记（专注、待办、吃饭、洗澡、生病、摸摸）；每 7 天总结这周开心、一般还是难过。📔 日记页能看到每天的专注分钟和时间线。
- **形象**：所有宝可梦都用 PMD SpriteCollab 的形象。新伙伴的形象第一次要联网下载，下载好之前先显示它的精灵球。
- **表情和动作**：形象来自 PMD SpriteCollab，每只有约 35 个动作（待机、8 方向走路、睡觉、吃东西、受伤、倒下、蹦跳、攻击…），动作跟着它在做的事变化；气泡里显示 PMD 头像，表情随心情和状态变化（开心、担心、难过、疼、晕…）。
- **对键盘鼠标做出反应**（可关）：你打字时它坐下陪你打字，连续打字 15 分钟没开番茄钟会建议你开一个；鼠标移动时它会看向光标；鼠标停在它身上会害羞，快速晃鼠标它会晕；离开 3 分钟它会睡觉。
- **全屏时躲开**：前台是全屏应用（视频、游戏、演示，包括 Safari 等浏览器的全屏视频）时自动隐藏，退出全屏后再出来（设置里可关，默认开）。
- **AI 聊天**（默认关闭）：设置 → AI 聊天，选服务商、填自己的 API key 和模型，然后右键「💬 聊天」。宝可梦按自己的性格和当前状态回答。对话不保存。
- **检查更新**：启动时和每天 3 次自动检查 GitHub 上的新版本（设置里可关）。有新版本时会**弹窗提醒**；也可以在 设置 → 更新 里操作。
- **自动安装**：选「下载并自动安装」后，软件会自己完成全部步骤：下载安装包到「下载」文件夹 → 退出 → 安装新版本 → 打开新版本。
  - 如果没能自动装好，下次启动时会提醒你，并保留下载好的安装包，点「手动安装」打开它自己装（macOS：把应用拖进「应用程序」；Windows：运行安装程序）。
  - 如果手动也没装好，设置 → 更新 里「检查更新」下方会出现「**安装遇到问题，手动下载安装包**」，点它会打开 GitHub 的发布页面。

## English

- **Diary**: the pet writes a daily entry in its own words (focus, to-dos, meals, baths, sickness, pats) and every 7 days
  says whether the week was happy, okay or sad. 📔 Diary shows focus minutes per day and a timeline.
- **Sprites**: every Pokémon uses its PMD SpriteCollab sprite. A new team member's sprite is downloaded the first time;
  until then its Poké Ball is shown.
- **Animations and emotions**: sprites come from PMD SpriteCollab, about 35 animations each (idle, walking in 8
  directions, sleeping, eating, hurt, fainting, hopping, attacks…) that follow what it's doing; speech bubbles show its
  PMD portrait, matching its mood and state (happy, worried, sad, pain, dizzy…).
- **Reacting to keyboard & mouse** (can be turned off): it types along while you type and suggests a Pomodoro after
  15 min of typing without one; it looks at the cursor; it gets shy when you hover over it and dizzy when you shake the
  mouse; it naps when you've been away 3 min.
- **Hiding over fullscreen apps** (videos, games, slides – including fullscreen video in Safari and other browsers),
  coming back when you leave fullscreen – on by default, can be turned off.
- **AI chat** (off by default): Settings → AI chat, pick a provider, enter your own API key and a model, then right-click
  "💬 Chat…". Your Pokémon answers in character from its current state. Conversations aren't saved.
- **Updates**: checks GitHub for a new release at start and three times a day (can be turned off in Settings). A new
  version **pops up a reminder**; Settings → Updates works too.
- **Installing by itself**: "Download and install automatically" does everything: downloads the installer to your
  Downloads folder → quits → installs the new version → starts it.
  - If that doesn't work, the next start tells you and keeps the downloaded installer: "Install by hand" opens it
    (macOS: drag the app into Applications; Windows: run the setup).
  - If installing by hand doesn't work either, Settings → Updates shows "**Trouble installing? Download the installer
    by hand**" below the update check, which opens the release page on GitHub.
